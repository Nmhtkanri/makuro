## 要点（詳細は AI解析ガイド.md）

- **ライブ本体**: `Y:\給与明細\R8年\6月\経費利用履歴 Rev4.xlsm`（月フォルダごと）。フォルダの.basとはモジュール名がドリフトしているので、**修正対象は live xlsm のVBAを正**とする。
- **分類の中心**: `c設定` の `Run_経費集計_設定シート版()` → `Collect_From_Source`。「設定」シートのキーワードで経費統合一覧表(34列)を優先順位順に判定し、集計シート（C=合計, D=夜間当番, E=RINK, F=手当2, G=顧客請求, **H=交通費**, **I=非課税精算(立替金)**, J=その他, K=テレワーク, L=請求日）へ転記。
- **既知の癖（2026-06-30修正済）**: 非課税精算(I)が備考フリーテキストの旧分類名を先取りして交通費(H)を奪うバグ → 照合を正式項目(内訳+交通機関+費用種別)に限定して解消。
- **機能(2026-06-30追加)**: SAP夜間当番手当（SAP_経費 D列業者名/F列説明に「顧客対応」or「顧客当番」）はC列(費用合計)を行ごとに ÷1.1 四捨五入で税抜補正（`Paste_SAP経費_From_File` 8b）。**入力は必ずSAPの生CSV（税込 2750/5500/1375 → 2500/5000/1250）。加工済み(2500等)を入れると二重控除で誤り。**
- **機能(2026-06-30追加 / Rev5〜)**: 夜間当番KWが説明(F列)のみにある行は業者名(D列)へ転記（`Paste_SAP経費_From_File` 8a）。下流`IsNightDutyVendor`がD列だけで判定しFのみだと顧客請求分に流れる問題への対処。Rev4(6月)は未適用。

## 解析・編集の鉄則

1. VBAは Excel COM で `.Export` して .bas を取り出す。
2. .bas は **Shift-JIS(cp932)**。読むだけならUTF-8変換コピー、編集は latin1 Node か `iconv`。UTF-8上書き厳禁。→ スキル `excel-vba` / `read-sjis` を併用。
3. 実データ走査は `Range.Value2` を2次元配列で一括取得（セル逐次は激遅）。
4. **検証は非破壊シミュレーションで**。主要Subは末尾`MsgBox`があり headless `Application.Run` でハングする。分類ロジックを別実装して旧/新を全行比較する。
5. 再インポートは COM `VBComponents.Remove`→`.Import`→`.Save`。Excelを閉じ、元xlsmはバックアップしてから。
6. 修正反映は集計の再実行が必要（実行時に集計シート自動バックアップ）。SAP機能は次回CSV取込から。
